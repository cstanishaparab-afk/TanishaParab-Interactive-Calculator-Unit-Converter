# Interactive Calculator & Unit Converter

A beginner-friendly command-line application developed using Python.

The project performs basic arithmetic operations and common unit conversions through an interactive menu.

## Features

### Basic Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

### Unit Converter
- Kilometers to Miles
- Celsius to Fahrenheit

### Input Validation
- Validates numeric input using `while` loops
- Handles invalid user input
- Prevents the program from crashing due to invalid numbers
- Validates menu choices

## Technologies Used

- Python 3
- Visual Studio Code
- Command Line Interface (CLI)
